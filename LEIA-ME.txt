TERAPIA BAR — OneSignal

1. Envie index.html, OneSignalSDKWorker.js e OneSignalSDKUpdaterWorker.js para a RAIZ do repositório GitHub BARTERAPIA (branch main).
2. Confira que o endereço publicado é https://gustavolavely.github.io/BARTERAPIA/ .
3. No OneSignal, configure URL do site https://gustavolavely.github.io e caminho/escopo do worker /BARTERAPIA/ .
4. Abra o site, entre na Área dos proprietários e clique em Ativar notificações de reservas.
5. Faça um envio de teste no painel OneSignal para conferir o recebimento.

IMPORTANTE: isso registra o navegador para notificações. O envio automático ao receber novas reservas exige uma integração servidor (Supabase Edge Function + Database Webhook), com credenciais secretas guardadas no servidor.

No iPhone, web push exige iOS/iPadOS 16.4+ e o site adicionado à Tela de Início como aplicativo web; GitHub Pages em subpasta pode precisar de manifest e ícones adequados para essa experiência.
